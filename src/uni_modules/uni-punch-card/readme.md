# uni-punch-card

「醒目大字卡」内容卡片组件，基于 uni-app（Vue 3）。

橙底 + 纯黑圆角卡 + 超大粗体字，正文里 `**文字**` 包围的部分自动换成高亮色，用来压重点。

## 功能

- 单字段正文，`\n` 分句、每句独占一行
- `**文字**` 行内高亮，可跨自动换行点（一句里强调词被折行也正确着色）
- 未闭合的 `**` 按普通文字原样显示，不吞字
- 内容少时卡片保持固定比例（480 × 656），正文垂直居中；内容多时卡片自动增高

## 安装

1. 将 `uni_modules/uni-punch-card` 整个目录拷贝到你的项目 `uni_modules/` 下；
2. easycom 会自动按标签引入，无需手动注册。

```json
// pages.json easycom
{
  "easycom": {
    "custom": {
      "^uni-punch-card$": "/uni_modules/uni-punch-card/components/uni-punch-card/uni-punch-card.vue"
    }
  }
}
```

## 使用

```html
<uni-punch-card content="把想说的话&#10;**变成一张**&#10;好看的卡片" />
```

## 属性

| 属性      | 类型   | 默认值 | 说明                                          |
| --------- | ------ | ------ | --------------------------------------------- |
| `content` | String | `''`   | 正文，`\n` 分句；`**文字**` 标记高亮重点       |

## 尺寸约定

组件 CSS 的 px 基准（480 宽 / 34 圆角 / 58 字号 / 85 行高 / 39 左右内距 / 158 上下内距）
与导出绘制器 `src/lib/card-painter.js` 里的 `P` 常量一一对应，改一边必须同步另一边，
否则「预览看到的」与「导出得到的」会不一致。
