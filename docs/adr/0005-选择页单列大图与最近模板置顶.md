# 0005 选择页改单列大图，最近使用模板置顶

选择页（`pages/index`）原为双列网格：每张缩略图装在 300×400rpx 的固定框内，一屏可平铺四张模板。用户决策改为**单列大图陈列**，并让**最近使用的模板自动排在首位**。本 ADR 记录该变更，并修订 ADR 0003 决策 5 中「仅作选择页角标」的表述。

## 决策内容

1. **陈列由双列网格改为单列**：`grid-template-columns` 由 `1fr 1fr` 改为 `1fr`，缩略图宽度由固定 300rpx 改为撑满内容区（654rpx = 750rpx 屏宽减两侧各 48rpx）。
2. **缩略图等宽陈列，`widthFix` 自适应高度**（2026-09-14 修订，原决策为「3:4 统一框 + `aspectFit`」）：每张铺满内容区宽度 654rpx，高度随卡片自身宽高比。原方案把四张图等比塞进同一个 654×872rpx 的框，但四张源图的宽高比跨度很大（票根卡 0.54、流光卡 0.69、大字卡 0.75、要点卡 0.90），等比缩放的必然结果是显示尺寸不齐：最窄的票根卡仅 470rpx 宽，最宽的要点卡 654rpx，相差 39%，实测观感明显别扭。改为等宽后四张左右边缘严格对齐，且不裁切任何内容。代价是高度不一（票根卡约 1213rpx，要点卡 654rpx），票根卡一屏几乎占满。
3. **最近使用模板置顶**：选择页的 `templates` 由常量改为 `computed`，把 `unicard_mine.lastTemplateId` 对应的模板移到首位，其余保持注册表原顺序。置顶只在页面层重排展示数组，**不改动 `TEMPLATES` 常量本身**，因此注册表顺序仍是稳定的默认顺序。
4. **保留「最近」角标**：置顶与角标同时存在，角标用于标定身份（避免用户误以为顺序固定）。角标与置顶共用同一个 id。
5. **修订 ADR 0003 决策 5**：该 id 由「仅作选择页角标」扩展为「作角标并驱动陈列置顶」。但决策 5 的实质约束不变，即**不驱动默认选中**：进入选择页不会自动跳转或预设某个模板，选模板仍须用户点击。

## Consequences

- `CONTEXT.md`「模板选择页」定义同步修订为「单列大图陈列，最近使用的模板置顶并带「最近」角标」。
- 一屏可见卡片数由约 4 张降为约 1.5 张，四个模板需向下滚动；单页元素量级不变（仍为 4 项），无列表性能问题。
- 等宽陈列的代价是高度不一：票根卡约 1213rpx，要点卡 654rpx。四张总高由统一框方案的约 3488rpx 增至约 3913rpx，滚动距离增加约 12%。
- 与 ADR 0003「选择页即首页、看模板全家福」的取向存在张力：单列放弃了「一屏看全」，换取「每张卡片细节可辨」。卡片细节（尤其深色要点卡与醒目大字卡的文字排版）是用户选择的主要依据，故取后者。
- 置顶会让卡片顺序随使用变化，位置记忆不再可靠（用户上次点的第二张，下次可能不在第二格）。这是置顶的固有代价，用角标缓解。
- ADR 0003 决策 1 与决策 4（每次写作均经选择页、素材库编辑直达输入页）不受影响。
