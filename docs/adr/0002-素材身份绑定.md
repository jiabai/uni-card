# 0002 素材身份绑定：草稿持有素材 id，而非内容指纹

素材自动归档（ADR 0001）需要 upsert 的身份规则——判定「这次出图是更新旧素材还是新建」。我们决定采用**身份绑定**：每套模板的草稿持有一个当前绑定的素材 id；出图成功时无绑定则新建并回写绑定，有绑定则更新该素材。被否决的替代方案：内容指纹（改一个字即成新素材，与「同一内容的迭代」心智相悖）与每次新建（同一草稿的 N 个微调版本会刷屏素材库）。

## Consequences

- 素材库「编辑」载入即换绑：编辑旧素材后再分享是**更新原素材**，不另存副本、不设「另存为」出口（衍生版本走「重置为默认」解绑另起）。
- 「重置为默认」与素材删除均须**同步解绑**，否则已删素材会被下次分享「复活」，删除行为不可信。重置仅作用于**当前模板**（另一模板草稿与绑定不动）。
- ~~绑定关系存于输入页配置缓存（`unicard_config`）内、按模板各持一份，不单独设键。~~ **修订（一期实现，2026-08-31）**：绑定改为独立键 `unicard_binding` 存储。原因：输入页对草稿的深监听会将页面内存中的 drafts 整包覆写 `unicard_config`，嵌入草稿的绑定字段每次编辑后被抹掉，第二次分享必然误建新素材——该缺陷由端到端验收发现，单测无法覆盖（无「页面 watch 覆写」路径）。独立键物理隔离后补「覆写不丢绑定」回归测试。
