# 0001 素材自动归档：分享即存稿

素材库（二期）需要素材来源。与其增加显式「存为素材」按钮（给分享主流程增加决策负担，违背无压原则），我们决定：输入页点「下一步」出图成功时，自动将当前内容归档为素材（upsert，同一内容更新不重复）。理由：「生成过卡片的内容」天然是「值得再次分享的内容」，这是最准确的入选标准，且用户全程零感知。

## Consequences

- 素材库会积累试验性半成品，靠二期关键字过滤兜底，不做入库门槛。
- 素材身份判定规则（upsert 的身份键）见 ADR 0002。
- 「分享过」成为素材的唯一入选标准，未来不得再加「收藏/标星」类显式入库动作（那会把工具拖回笔记应用方向）。
