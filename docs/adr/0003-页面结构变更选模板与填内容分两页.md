# 0003 页面结构变更：选模板与填内容分两页

V3.7 及以前的设计是「输入页同页两段」：顶部缩略图选择区选模板、下方编辑区填内容，配套原则「老用户零成本路径」（默认选中最近使用模板，直接开写）。用户决策推翻该结构：**模板选择独立成页**——选择页为首页（`pages/index`），点选模板后进入输入页（`pages/edit`），选模板和填内容不在同一个页面。

## 决策内容

1. **「老用户零成本路径」原则取消**：每次写作均经选择页，不设「默认选中直接开写」与「继续写」快捷入口；
2. **出口标准放宽**：从打开到拿到可分享图片 ≤**4** 次点击（原 ≤3）；
3. **好友转发落地选择页**（原落地输入页）：好友多为新访客，看模板全家福即「了解产品」的第一步，与「选择页即首页」自洽；
4. **素材库「编辑」直达输入页**（跳过选择页，自动选中该素材的模板）：编辑目标已由素材记录确定，中途再选是流程倒退；「每次都经选择页」原则只约束新写作入口，不管编辑既有素材；
5. **最近使用模板 id（`unicard_mine`）保留但改用途**：不再驱动默认选中，仅作选择页「最近」角标；
6. **切换轻 Toast（V3.7 决策）随之废止**：其触发场景（同页切换模板）已不存在；草稿按模板独立记忆不变。

## Consequences

- 三段流程由「同页两段 + 预览」变为「三段三页」：选择页 → 输入页 → 预览页；返回路径逐级（预览→输入→选择），草稿各层无损；
- 代码重构列为一期后置项（见设计文档 10.2）：选择区抽出为首页、编辑区迁 `pages/edit`、`onShareAppMessage` 落地路径改选择页、切换 Toast 移除；服务层（注册表 / 存储 / 素材 / painter）与缩略样图零改动；
- 输入页术语含义收窄（纯填写，不再含选模板）；CONTEXT.md 术语表同步；
- 每次写作多一次页面跳转，为结构性代价，用户已知情并接受（放弃零成本路径时的显式取舍）。
