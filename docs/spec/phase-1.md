# 一期 · 核心分享闭环

## Problem Statement

用户想把一段自己想说的话变成一张好看的图片卡片发进微信私域（好友 / 群聊 / 朋友圈），现在没有顺手的工具：现有工程只是一个卡片渲染演示页——模板用文字下拉选择、卡片常驻同屏预览、没有任何分享或导出能力。用户写完内容后拿不到可分发的图片，「分享」这个唯一目标落不了地。

## Solution

把演示页拆成两段两页流程：**选择页（看图选模板）→ 输入页（填内容）→ 点「下一步」直接出图 → 分享图片页（2 按钮操作栏）**。分享图片页提供「分享图片」（系统级图片分享菜单，真正把图片文件发给好友）与「保存到相册」（存相册，朋友圈路径由此吸收）。出图成功的同时，内容自动归档为素材（身份绑定 upsert），为二期素材库积累数据。全程无账号、无注册、本地优先。

## User Stories

**选择页（选模板）**

1. 作为用户，我想以缩略图的方式浏览所有模板并看图选择，这样我不需要理解文字描述就能预判卡片的最终观感。
2. 作为老用户，我想在最近使用的模板上看到「最近」角标，这样我能一眼找到常写的模板。
3. 作为用户，我想让每套模板各自记住我填过的内容，这样我换模板再回来时内容互不污染、随时可回。

**输入页（写内容）**

4. 作为用户，我想在写作时只面对纯文本输入区、不被卡片预览打扰，这样保持「像发消息一样」的无压输入心智。
5. 作为用户，我想让正在编辑的内容自动存为草稿，这样中断后回来不丢任何字。
6. 作为用户，我想在字数超长时只收到提示而不被硬性拦截，这样长文也能成卡。
7. 作为用户，我想一键「重置为默认」回到出厂示例，这样试错成本为零；且重置前有二次确认，避免误触清空我的内容。
8. 作为票根卡用户，我想只填写正文、DATE 与 BY（author），这样卡片聚焦内容、日期与署名，不显示 TOTAL MEMOS / TOTAL DAYS。
9. 作为流光卡用户，我想填写标题 / 日期 / 正文 / 署名 / 二维码内容，这样产出深色金句风格的卡片；二维码留空则不显示。

**出图与分享图片页**

10. 作为用户，我想点一下「下一步」就立刻出图并进入分享图片页，这样从写作到出卡片只需一次点击。
11. 作为用户，当正文为空时我想被轻提示「先写点内容吧」并留在输入页，这样不会看到一张空白卡片。
12. 作为用户，我想在分享图片页看到卡片图片按屏宽约 90% 居中展示，这样所见即所得地确认成图。
13. 作为用户，我在分享图片页想改内容时凭返回手势/返回按钮即可回到输入页，这样不需要学习额外的「编辑」入口（页面也不设）。

**分享图片与保存（含朋友圈路径）**

14. 作为用户，我想点「分享图片」直接唤起系统图片分享菜单、把卡片图片文件发给好友，这样分享出去的是图而不是小程序卡片。
15. 作为用户，我想点「保存到相册」把当前卡片图（2x 高清导出）存入系统相册，这样图片发朋友圈或收藏都够清晰。
16. 作为用户，保存成功后我想收到「已保存到相册」的提示，这样我知道朋友圈路径就是「存相册后去微信发布」，不需要一个单独的朋友圈按钮。
17. 作为用户，当我首次保存被系统弹授权、又误拒了相册权限时，我想被引导到设置页开启权限，这样不会卡死在失败提示上。
18. 作为用户，当我的内容超长导致导出画布超过平台上限时，我想收到明确提示让我精简内容，这样导出不会静默失败。

**素材归档（数据积累，界面在二期）**

19. 作为用户，我想让我每次成功出图的内容自动归档为素材，这样好内容天然沉淀下来供日后一键再次成卡（无需任何「保存」操作）。
20. 作为用户，当我基于同一草稿反复修改再分享时，我想让它更新同一条素材而不是刷出 N 个微调版本，这样素材库干净可信。
21. 作为用户，当我删除某条素材后（二期界面），我想让绑定它的草稿同步解绑，这样已删内容不会被下次分享「复活」。

**工程与数据基建**

22. 作为开发者，我想让存储键统一为 `unicard_*` 前缀并完成旧键一次性迁移，这样命名一致且不触碰 flomo 谐音的合规红线。
23. 作为开发者，我想让当前选中模板以模板 id 持久化，这样注册表顺序调整不影响用户的选择。
24. 作为开发者，我想让模板注册表统一驱动选择区、渲染分支与主题联动，这样新增模板零页面代码改动。
25. 作为开发者，我想完成 config.js 命名统一（`glowConfig` 补齐 qrText、移除兼容导出），这样代码语言与领域术语一致。

## Implementation Decisions

- **两段两页与页面拆分**：演示页拆为选择页（`pages/index`，首页）、输入页（`pages/edit`）、分享图片页（`pages/share`）。主流程不经预览页（`pages/preview` 保留供二期素材库「用这条分享」复用，其「生成分享图」与右上角「···」转发小程序卡片一并保留）。输入页「下一步」直接出图；分享图片页是纯出口——2 按钮（分享图片 / 保存到相册）、无模板操作、无「编辑文字」入口。
- **模板注册表**：服务层注册表模块，字段固定五项（id / name / comp / thumb / theme），驱动缩略图选择区、渲染分支与页面主题；各模板默认内容不进注册表，仍以 config 模块为唯一来源。
- **缩略图选择区**：横向滑动区，每模板一张预生成静态样图（置于 static/templates/），240×300rpx 圆角卡片 + 名称小字；选中态主色描边，其余半透明。
- **模板记忆**：最近使用模板 id 持久化于用户设置存储键，作选择页「最近」角标（不再驱动默认选中）。
- **素材自动归档（ADR 0001）**：出图成功即归档，无显式存稿动作。身份绑定规则（ADR 0002）：每套模板的草稿持有当前绑定的素材 id；出图成功时无绑定 → 新建并回写绑定，有绑定 → 更新该素材（刷新 fields 与 updatedAt）；「重置为默认」与素材删除均同步解绑。绑定关系存于独立键 `unicard_binding`（物理隔离草稿深监听覆写）。
- **存储键**：`unicard_config`（编辑草稿）/ `unicard_mine`（昵称、统计开关、最近模板 id）/ `unicard_library`（素材数组）/ `unicard_binding`（身份绑定）。旧键 `uni-card-demo-config` 首次读取回退并写回新键，下版本移除。读写统一 try/catch 静默回退。
- **导出（canvas 2d 重绘）**：输入页与预览页各自挂隐藏导出画布（`#exportCanvas`，`type="2d"`），经共享模块 `lib/card-export.js` 绘制，避免两页各维护一套导出代码。绘制与组件 px 尺寸基准一致（ticket 520 / glow 480），整体 ×2 高清；两遍绘制——先 measure 内容高度，再设画布尺寸落笔，上限 4096px；装饰 PNG 预载后逐层绘制，二维码用矩阵核心在导出画布直接重画；`toTempFilePath` 生成临时文件供保存相册复用。
- **保存相册**：`saveImageToPhotosAlbum` + `scope.writePhotosAlbum` 授权流；拒绝后 showModal 引导 openSetting。
- **分享图片**：`wx.showShareImageMenu`（基础库 2.14.3+）直接唤起「发送给朋友 / 保存到相册」系统菜单，真正把图片文件发出去；低版本回退提示长按图片分享。分享图片页大图 `show-menu-by-longpress` 支持长按系统菜单。
- **小程序卡片转发（预览页兜底）**：`onShareAppMessage` 同步返回（固定标题、落地选择页、固定产品封面）；一期不做内容透传、不接 msgSecCheck（二期随「导出图作封面」接入）。
- **config 命名统一**：`legacyConfig` → `glowConfig` 并补齐 qrText 默认值；移除 `cardConfig` 兼容导出。缓存内部键不受影响。
- **架构约束（沿用）**：uni_modules 必须在 src/ 内；easycom 用 `@/` 前缀；二维码仅引入纯 JS 矩阵核心；平台专属逻辑收敛在 `#ifdef MP-WEIXIN` 内；rpx 为主、二维码 canvas 用 px。
- **平台边界**：不配置 tabBar（选择页为唯一首页）；小程序无法直发朋友圈，不做绕道方案。

## Testing Decisions

- **唯一自动化测试接缝：服务层纯 JS 模块**（Vitest）。只测外部行为，不测实现细节。覆盖：
  - 注册表模块：id 查询、字段完整性；
  - 存储封装：新键读写、旧键 `uni-card-demo-config` 一次性迁移、异常静默回退、身份绑定的存取；
  - 素材归档：四条身份规则——无绑定新建并回写、有绑定更新（含 updatedAt 刷新）、删除时解绑对应草稿、重置为默认解绑。
- **人工验收（不自动化，平台绑定）**：canvas 导出与预览的视觉一致性；保存相册授权流；`wx.showShareImageMenu` 图片分享；缩略图选择区交互——微信开发者工具 + 真机。
- **产物验收**：编译产物中 `<svg>` 与 `@media` 命中为 0。
- **出口标准**：看图选模板 → 填内容点「下一步」即见卡片；从打开到拿到可分享图片 ≤3 次点击（选模板 → 下一步 → 分享图片）；导出与预览视觉一致；素材正确累积、再次分享可更新。

## Out of Scope

- 素材库页面（列表 / 选用 / 编辑 / 删除 / 关键字过滤 / 备注标签）——二期；一期只积累数据。
- `msgSecCheck` 内容安全与「导出图作转发封面」（含异步预绘链路）——二期。
- 新模板风格位、缩略图产出切换 automator 脚本、动态缩略可行性评估——二期。
- 署名自动注入 BY 字段、「我的」页、tabBar——三期；票根卡不再提供 TOTAL 统计字段。
- 云开发备份、内容安全覆盖面复核——四期。
- 明确不做：每日回顾、批量回顾、点赞/埋没、标签树、多级文件夹、「另存为新素材」出口。
- appid 填入 manifest：发布前操作项，不属代码改造。
